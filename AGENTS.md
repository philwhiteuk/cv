# AGENTS.md

## Quick Start

- **Branch**: work on `main`
- **Commits**: use [gitmoji](https://gitmoji.dev/) conventional commits
- **Push**: directly to `main`

## Style

Keep it **terse, informal, easy to read**. Short sentences. Plain language. No fluff.

## Tech

Jekyll static site. Ruby. Liquid templates. SASS for styles.

## Structure

- `_config.yml` - site config
- `_data/` - YAML data files
- `_layouts/` - page layouts
- `_includes/` - reusable components
- `_sass/` - styles
- `pages/` - top-level pages
- `_projects/`, `_interests/`, `_tags/` - collections

## When in doubt

Match existing patterns. Keep it simple. Ship it.

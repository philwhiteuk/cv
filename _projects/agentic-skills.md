A personal, open-source collection of *8 reusable LLM skills* built to automate my own day-to-day engineering workflow — structured prompts covering the full software delivery lifecycle: writing and classifying specs, turning approved specs into implementation plans, PR triage, driving PRs to merge, codebase walkthroughs, Slack messaging, and prose editing for plain, direct writing.

Framework-agnostic prompts, usable with any LLM-powered coding tool, and installable directly as a Claude Code plugin (`claude plugin add philwhiteuk/llm-skills`). MIT licensed.
